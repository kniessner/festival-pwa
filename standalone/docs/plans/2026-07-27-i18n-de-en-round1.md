# DE/EN i18n Round 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a German/English language toggle to the standalone app, translate every hardcoded UI-chrome string, serve English Program/Timetable content scraped from the festival's own `/en/` pages, and make `update.sh` refresh both languages in one run.

**Architecture:** A new `js/i18n.js` module holds a flat `STRINGS.de`/`STRINGS.en` dictionary plus `getLang()`/`setLang()`/`t()`. `store.lang` drives a fallback-chain data loader (`data/en/<file>` → `data/<file>`) and every view swaps hardcoded German literals for `t('key')` calls. The Python scraper scripts gain a `lang` parameter for the handful of values that are genuinely language-specific (day names, page titles); everything else on the festival's `/en/` pages is already translated by the site itself, so pointing the same extractors at a different URL is sufficient. `update.sh` runs the existing German scrape pass, then a second English pass, in one invocation.

**Tech Stack:** Vanilla ES modules, plain CSS, Python 3 stdlib (`re`, `urllib`) for scraping, bash for orchestration. No npm, no bundler, no framework, no test runner — unchanged from the rest of the project.

## Global Constraints

- **Zero build step** — no npm, no bundler, no transpile. Edit files, reload browser.
- **Vanilla only** — no React/Vue/Svelte; native ES modules only.
- **Behavior-preserving for German** — with `store.lang === 'de'`, output must be identical to today's app.
- **Scope** — only `2026-festival-pwa/standalone/`. `dist/` is generated by `deploy.sh` and is not hand-edited (any change needed there happens automatically the next time someone runs `deploy.sh`, which also auto-commits/pushes to `gh-pages` — do not run it as part of this plan).
- **Round 2 is out of scope** — do not touch `_extract_faq.py`, `data/info.json`, `data/news.json`, or `data/cashless.json`/`data/faqs.json` content. English users seeing German Info/FAQ/Cashless content this round is expected, not a bug.
- **No test runner exists** — every task is verified by running `./scripts/start.sh` and driving the flow in a browser at `http://localhost:8767/` (or whatever port `start.sh` prints), plus `node --check` for JS syntax and direct `python3` invocations for the scraper scripts.
- **`cache.addAll()` is atomic** — never add a file to `sw.js`'s `SHELL_ASSETS` that doesn't exist yet, or the entire offline precache silently breaks for every user.

const LANG_KEY = 'bucht-lang';

export function getLang() {
    const stored = localStorage.getItem(LANG_KEY);
    if (stored === 'de' || stored === 'en') return stored;
    const initial = navigator.language && navigator.language.toLowerCase().startsWith('en') ? 'en' : 'de';
    localStorage.setItem(LANG_KEY, initial);
    return initial;
}

export function setLang(lang) {
    localStorage.setItem(LANG_KEY, lang);
    document.documentElement.lang = lang;
}

export function t(key, vars) {
    const str = STRINGS[getLang()]?.[key] ?? STRINGS.de[key] ?? key;
    if (!vars) return str;
    return Object.entries(vars).reduce((s, [k, v]) => s.replace(`{{${k}}}`, v), str);
}

import { DATA_FILES } from './config.js';
import { getLang } from './i18n.js';

export const store = {
    currentPage: 0,
    pageData: {},
    lang: getLang(),
    ttFilters: { stage: 'all', category: 'all', genre: 'all', day: 'all' },

};

async function fetchLocalized(file, lang) {
    if (lang !== 'de') {
        try {
            const res = await fetch(`data/${lang}/${file}`);
            if (res.ok) return await res.json();
        } catch (e) {
            // fall through to German
        }
    }
    const res = await fetch(`data/${file}`);
    return res.json();
}

export async function loadData() {
    for (const [slug, file] of Object.entries(DATA_FILES)) {
        try {
            store.pageData[slug] = await fetchLocalized(file, store.lang);
        } catch (e) {
            console.error('Failed to load', file, e);
        }
    }
}

export async function loadManifest() {
    try { return await (await fetch('data/_manifest.json')).json(); }
    catch { return null; }
}
