## Executive Summary

The Festival PWA plugin is functionally complete at v1.3.0. It is a WordPress plugin that provides an offline-capable Progressive Web App for festival websites. Content is fetched from a source WordPress site (e.g. `bucht-der-traeumer.de`), cached as JSON, and served via a Service Worker for full offline availability. The project also includes a standalone preview mode that works without WordPress.

**Status:** Functional but has data quality issues in the production cache.

---

## Architecture

```
Source WP (bucht-der-traeumer.de)
    ↓ wp_remote_get()
Festival PWA Plugin (Host WP)
    ├─ Admin Settings (page builder, source URL, sync)
    ├─ Content Sync (fetch HTML → extract → save JSON)
    ├─ REST API (serve manifest + pages + design tokens)
    └─ PWA Frontend (app shell + vanilla JS controller)
        ↓ registerSW()
Browser (Guest phone)
    ├─ Service Worker (precaches shell + manifest + selected pages)
    └─ Cache Storage (offline-first, all content cached)
```

## Data Quality Issues

### Empty FAQ Answers
Both `preview/data/cashless.json` and `pwa/data/cashless.json` contain 16 questions with empty `answer` fields. The sync engine extracted questions from headings but failed to capture paragraph content below them. This is likely because the source site's FAQ answers are hidden behind accordions or loaded via JS.

### Incomplete Production Cache
The production `pwa/data/_manifest.json` only lists **1 page** (`cashless`). Performances and workshops are missing, despite having partial JSON files. This indicates the last sync did not complete successfully or only one page was configured at the time.

### Corrupt/Empty JSON Files in Production
- `.json` — a file literally named `.json` with empty slug/title/content
- `faq.json`, `info.json`, `tickets.json` — all empty/minimal
- These were likely created by incomplete or failed sync attempts.

### Missing Info Page Data
The `info.json` in production has `"content": ""`. If Info is selected as a page source, it needs content or should be removed from the PWA pages list.
